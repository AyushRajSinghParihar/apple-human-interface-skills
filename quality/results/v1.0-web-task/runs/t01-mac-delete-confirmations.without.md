Apple’s alert guidance specifically permits Return confirmation for a deliberately chosen action such as Empty Trash. For unexpected destructive choices, it recommends destructive styling, a Cancel exit, and—when deliberate reading is needed—no default button. **Making Cancel the default is not the prescribed fix.** The same guidance discourages alerts for common, undoable actions. [Apple HIG: Alerts](https://developer.apple.com/design/human-interface-guidelines/alerts?trk=article-ssr-frontend-pulse_little-text-block)

When testing keyboard behavior, distinguish an **initial Return press** from intentionally focusing and activating a button. For B, also check that the keystroke used to invoke the command does not carry through and confirm the newly presented alert.
