# Apple HIG: layout and organization

Start with data structure: a text list, image collection, flat comparison table, hierarchical outline or column browser, or coordinated split panes. Use spacing before adding group borders. Separate pane tabs from app-level tab bars, and check focus growth, resizing, hierarchy state, and platform support.
