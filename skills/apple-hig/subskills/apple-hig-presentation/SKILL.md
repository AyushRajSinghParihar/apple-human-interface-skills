# Apple HIG: presentation

Choose presentation from urgency, scope, duration, and whether the parent must remain usable. Reserve alerts for critical actionable interruptions; sheets for scoped tasks; popovers and panels for contextual tools; windows for sustained parallel work. Define saving, cancellation, resizing, focus, and return context before styling. Read platform sections for modal scope and spatial placement.
