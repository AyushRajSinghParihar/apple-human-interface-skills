# Apple HIG: Platform and task adaptation

Use this family to select and compose topic procedures. Infer the platform and
requested work from the supplied project; preserve its framework and constraints.

## Work through the decision

1. Identify the person’s primary task and the target platform before translating a screen. Read that platform’s procedure; use Principles to resolve hierarchy and Designing for games only for gameplay.
2. Compare navigation, window/scene model, primary input, attention duration and state restoration. Preserve the product task while changing the interaction appropriate to the destination platform.
3. For device changes such as opening an iPhone Duo or resizing an iPad window, specify what selection, editing state and route survive each transition.
4. Deliver a platform-decision matrix or an adaptation patch, with concrete acceptance scenarios for each materially different interaction.

## Completion evidence

Report the concrete decisions or changes, their source support, and which checks
passed, failed or were not executed. A source citation or a list of links is not
the requested work product. Retain platform exceptions and unresolved source
conflicts; the absence of a platform subsection does not establish support.
