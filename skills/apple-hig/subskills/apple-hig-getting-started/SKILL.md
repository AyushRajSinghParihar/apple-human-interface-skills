# Apple HIG: Getting Started

Read the relevant device guide before making layout or input decisions. Use design principles to evaluate tradeoffs, then select the game or iPhone Duo guide when its constraints apply. Preserve the product’s purpose and user state while adopting each platform’s native interaction model. Follow the linked foundations, input, and technology guidance when a specific decision needs more detail.
