# Rating indicators

Source: [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/rating-indicators)  
Snapshot: 2026-10-25. Original implementation guidance derived from the source.

A macOS rating indicator displays an ordered row of symbols, conventionally stars. It rounds values to whole symbols, maintains fixed symbol spacing, and does not resize symbols to consume the component width.

<a id="Best-practices"></a>
## Best practices

Allow people to change a list item's rating directly in the list rather than opening a separate editing screen. If using a custom symbol, make the ranking meaning as clear as the familiar star.

<a id="Platform-considerations"></a>
## Platform considerations

No additional macOS rules are specified. This rating-indicator component is unsupported in iOS, iPadOS, tvOS, visionOS, and watchOS.
