# Get people into a safe first task

Read [the onboarding guide](../../references/onboarding.md). The workflow is application advice; the source adds no separate platform rules.

Inspect the first valuable task, true prerequisites, tutorial/setup flow, permission needs, platform, and create/review/adapt intent. Distinguish completed launch from onboarding and unavoidable prerequisites from optional configuration. Record skip persistence and later access from implementation; a Skip button alone is insufficient evidence.

Prefer safe learning through interaction and nearby task-specific tips over memorization slides. Keep prerequisites brief. Optional tutorials must be skippable, remember the decision across launches, and remain accessible later. Package enough initial content for interaction while larger assets download. Postpone optional preferences, permissions, ratings, and purchases until relevant value/commitment; only indispensable private-resource needs justify contextual explanation during onboarding. Integrate unavoidable legal content without derailing learning rather than treating the HIG as authority on legal requirements.

Implement the authorized first-use/skip/resume behavior, provide a prerequisite-versus-optional task flow, or review exact delay and forced-learning defects. Preserve the user's product scope rather than inventing a new multi-step signup funnel.

**Worked transformation:** Before: a drawing app requires six tutorial slides, notification consent, and a rating before opening a canvas; skipped slides return next launch. Decision: learning is blocking value and skip is not respected. After: open a safe sample canvas, introduce one relevant tool in context, postpone unrelated requests, and retain optional tutorial access through Help.

Deliver the artifact, initial task, prerequisite rationale, skip memory, and later-help route. Verify fresh/returning/skipped users, unavailable assets, denied optional permission, and re-entry. Fail for repeated skipped onboarding, optional setup blocking all value, or launch disguised as passive tutorial time. Report actual persistence/device execution separately from flow inspection.

Load [launching](../apple-hig-launching/SKILL.md), [offering-help](../apple-hig-offering-help/SKILL.md), or [managing-accounts](../apple-hig-managing-accounts/SKILL.md) for the affected prerequisite.
