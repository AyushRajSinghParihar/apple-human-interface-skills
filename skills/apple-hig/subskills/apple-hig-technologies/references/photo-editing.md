# Photo editing

Source: [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/photo-editing) · Retrieved 2026-10-25.

This is original application guidance based on the source text. Independent media review is recorded separately in the coverage report.

A Photos editing extension appears from edit mode in a modal with a system top toolbar. Saving creates a new file so the original remains intact.

<a id="Best-practices"></a>
## Best practices
Confirm cancellation only when changes exist, explaining that the edits will be lost. Use the provided top toolbar instead of adding a second one. Let people preview the result before dismissing the extension. Use your containing app’s icon so the editing extension’s origin is recognizable.

<a id="Platform-considerations"></a>
## Platform considerations
No additional iOS/iPadOS/macOS rules; tvOS/visionOS/watchOS are marked unsupported.
