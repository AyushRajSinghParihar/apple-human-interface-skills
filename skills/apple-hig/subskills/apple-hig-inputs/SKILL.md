# Apple HIG: Inputs

Identify the device, primary input, and available accessibility alternatives. Read that input’s reference and its platform subsection before choosing gestures or control mappings. Preserve system-reserved behavior and familiar semantics; use custom interactions only where the task benefits, with discoverable alternatives and feedback. Test transitions between input methods as well as each method independently.
