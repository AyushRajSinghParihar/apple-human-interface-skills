# Combo boxes

Source: [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/combo-boxes)  
Snapshot: 2026-10-25. Original implementation guidance derived from the source.

A macOS combo box combines editable text with a pull-down list. People can choose a suggestion or enter a custom value; typing a custom value does not add it to the list.

<a id="Best-practices"></a>
## Best practices

Start with a meaningful listed value where possible, even if it is not the first choice. Introduce the expected category with a title-case label ending in a colon. Populate the list with likely, relevant values while retaining free entry. Keep choices short enough to fit the field without truncation.

<a id="Platform-considerations"></a>
## Platform considerations

Combo boxes are unsupported in iOS, iPadOS, tvOS, visionOS, and watchOS.
