# Image wells

Source: [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/image-wells)  
Snapshot: 2026-10-25. Original implementation guidance derived from the source.

An image well is an editable image presentation. A selected well supports copy, paste, and deletion; a new image can be dropped into it without first selecting the well.

<a id="Best-practices"></a>
## Best practices

If a picture is required, restore an appropriate default after clearing the well. When supporting copy and paste, expose standard Edit-menu commands and their normal shortcuts so both menu and keyboard workflows work.

<a id="Platform-considerations"></a>
## Platform considerations

Image wells are specific to macOS and unsupported in iOS, iPadOS, tvOS, visionOS, and watchOS.
