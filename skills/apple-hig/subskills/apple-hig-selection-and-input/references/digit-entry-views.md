# Digit entry views

Source: [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/digit-entry-views)  
Snapshot: 2026-10-25. Original implementation guidance derived from the source.

A tvOS digit-entry view occupies the screen and supplies a numeric keyboard for a sequence such as a PIN. A title and explanatory prompt can appear above the digits.

<a id="Best-practices"></a>
## Best practices

Mask sensitive entry with secure digit fields, which show asterisks rather than exposed digits. Explain why the digits are required through a clear title and prompt.

<a id="Platform-considerations"></a>
## Platform considerations

This component is specific to tvOS and unsupported in iOS, iPadOS, macOS, visionOS, and watchOS.
