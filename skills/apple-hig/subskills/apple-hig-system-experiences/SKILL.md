# Apple HIG: system experiences

Choose the system surface by duration and intent: a widget for periodic glanceable content, Live Activity for a bounded evolving task, notification for a timely event, control/shortcut for a direct action, and complication for watch-face information. Define privacy, deep links, state freshness, and fallback behavior. Consult exact family dimensions and platform contexts; shared frameworks do not imply identical support or interaction.
