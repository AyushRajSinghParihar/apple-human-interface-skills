# Apple HIG: navigation and search

Map the hierarchy and query scope before choosing controls. Use tabs for stable top-level destinations, sidebars for broader hierarchies, and search placement that communicates global versus local scope. Preserve navigation state, empty destinations, and access as windows resize. Read the platform-specific rules before transferring an iPhone pattern to iPad, Mac, television, watch, or spatial windows.
