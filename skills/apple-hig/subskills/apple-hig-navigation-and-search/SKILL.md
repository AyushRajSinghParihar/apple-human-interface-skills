# Apple HIG: Destinations, scope and restoration

Use this family to select and compose topic procedures. Infer the platform and
requested work from the supplied project; preserve its framework and constraints.

## Work through the decision

1. Map top-level destinations, hierarchy, selected objects and search scope. Choose Sidebars, Tab bars, Search fields, Path controls or Token fields according to that structure.
2. Keep navigation distinct from commands and filtering. Preserve selected destination and useful search state when the window changes size or the person returns from detail.
3. Define empty results, dismissal and keyboard/focus paths where search is involved. Check that every destination remains discoverable in the compact and expanded arrangements.
4. Deliver the destination/search contract and concrete transition checks; apply or review it in the existing framework without substituting an unrelated navigation architecture.
