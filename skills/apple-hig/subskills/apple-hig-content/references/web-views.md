# Web views

Source: [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/web-views)  
Snapshot: 2026-10-25. Original implementation guidance derived from the source.

A web view embeds HTML or other web content within an app, as when a mail reader displays a richly formatted message.

<a id="Best-practices"></a>
## Best practices

Enable back and forward navigation and provide corresponding controls when people can visit several pages. Those navigation behaviors are supported but are not automatically available. Keep embedded browsing appropriate to the app's immediate context; brief access to a website can be useful, while recreating Safari's general browser feature set is discouraged.

<a id="Platform-considerations"></a>
## Platform considerations

No additional iOS, iPadOS, macOS, or visionOS rules are specified. Web views are unsupported on tvOS and watchOS.
