# SF Symbols animation examples

Source: [Apple HIG SF Symbols](https://developer.apple.com/design/human-interface-guidelines/sf-symbols).

## Visibility and emphasis

Appear brings symbol content into view; the antenna, photo stack, and waveform
examples expose how annotated layers can enter in a meaningful order. Disappear
removes the folder, lightbulbs, and conversation symbols from view. Choose these
effects for an actual visibility transition.

Bounce briefly changes the symbol or its layers and then settles back. Scale
changes emphasis by keeping the new size until the effect or scale changes;
the demonstration later returns to the earlier size to show both states.
Pulse varies opacity in the relevant layers, whereas Breathe combines opacity
with expansion and contraction. Keep a status symbol's base meaning recognizable
while using these differences to communicate the intended event or activity.

## State transitions

Replace transitions between different symbols: the examples exchange a grid for
a list, rain for partly cloudy weather, and a microphone for a close action. The
configurations differ in how the departing and arriving shapes scale, so choose
the transition that fits the state change rather than using one motion everywhere.

Magic Replace preserves a related base shape while adding a warning badge,
drawing a microphone slash, or changing a profile's checkmark to a cross. Use it
when the relationship between states should remain clear. Unrelated shapes use
the ordinary replacement fallback rather than sharing this transformation.

## Activity and direction

Variable Color changes the emphasis of individual paths, such as successive
speaker waves, Wi-Fi arcs, or sprinkler droplets. This can show progress or
ongoing activity without moving the whole symbol.

Wiggle follows the symbol's meaningful axis: an arrow moves vertically, photos
tilt, and the vehicle-related example moves laterally. Rotate can turn an entire
gear or only an appropriate part, such as fan blades while the fan's housing
remains steady. Select layer behavior to reinforce what the symbol represents.

These demonstrations compare available effects; they do not recommend playing
every effect together. Give each animation a specific communication purpose and
keep its strength and repetition appropriate to the task and the app's tone.
