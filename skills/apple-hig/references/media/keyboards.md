# Keyboard visual examples

Source: [Apple HIG keyboards](https://developer.apple.com/design/human-interface-guidelines/keyboards).

## Physical typing with a virtual accessory

The person types on a visible physical keyboard while a small virtual accessory
floats just above it. The accessory updates as typing proceeds and provides text
completion and other controls near the hands. A hardware keyboard does not remove
all virtual typing UI; leave room for the system's accessory presentation.
