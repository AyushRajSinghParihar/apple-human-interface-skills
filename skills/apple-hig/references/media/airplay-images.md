# AirPlay visual examples

Source: [Apple HIG AirPlay](https://developer.apple.com/design/human-interface-guidelines/airplay).

The supplied audio compatibility icon uses concentric radiating arcs above a
triangle; its video counterpart uses a display outline above a triangle. The
black, white, and custom-color examples retain those distinct media meanings.
Select the appropriate supplied artwork and retain legibility against the actual
surface. The source separates compatibility artwork from an interactive player
control; a recognizable mark alone does not make a custom button appropriate.

The player screenshot demonstrates familiar playback, seeking, caption, and
output controls around the content, with AirPlay in the lower-right control area.
The local article preserves using the standard player and the specified placement
when custom controls are necessary. Theme changes adapt contrast, not action
meaning or the distinction between audio and video.
