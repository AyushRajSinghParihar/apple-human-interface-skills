# Drag and drop visual examples

Source: [Apple HIG drag and drop](https://developer.apple.com/design/human-interface-guidelines/drag-and-drop).

## From a file to spatial content

The meteor starts as an item in Files. During the drag it remains recognizable as
a small file representation; after it is dropped into open space above a table,
the 3D object opens at that location. Preserve the connection between source item,
drag representation, and result. Dropping a supported 3D file outside a window can
produce useful spatial content rather than only transferring a flat thumbnail.
