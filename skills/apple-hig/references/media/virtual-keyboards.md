# Virtual keyboard visual examples

Source: [Apple HIG virtual keyboards](https://developer.apple.com/design/human-interface-guidelines/virtual-keyboards).

## Standard typing in a spatial presentation

The floating keyboard shows its normal letter grid and accessory controls while
hands tap keys directly. Keys highlight, the entry changes, and suggestions update
without the app inventing another typing surface. Use the system keyboard's
spatial presentation and appropriate input configuration, while keeping the
surrounding task usable as the keyboard appears or disappears.
