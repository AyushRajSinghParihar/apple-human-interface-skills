# Alert visual examples

Source: [Apple HIG alerts](https://developer.apple.com/design/human-interface-guidelines/alerts).

## Confirmation attached to context

In the first sequence, choosing permanent deletion in a Freeform window presents
a confirmation in front of that window while the initiating content remains
visible behind it. In the second, moving the parent window through the room also
moves the still-open alert. The decision stays spatially connected to the content
it affects. Preserve that relationship instead of leaving a confirmation behind
at an unrelated point in the person's surroundings.
