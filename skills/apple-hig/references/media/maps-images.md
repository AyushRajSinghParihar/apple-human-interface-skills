# Map visual examples

Source: [Apple HIG Maps](https://developer.apple.com/design/human-interface-guidelines/maps). Snapshot: 2026-10-25.

These original notes describe inspected map examples and appearance alternatives. The [main guide](../../subskills/apple-hig-technologies/references/maps.md) retains the source's platform and numerical requirements. Specific businesses, airports, roads, and dates are examples.

## Emphasis and selection

The default and muted map pair shows the same 3D geography with different visual emphasis. Muting quiets the base geography so custom information can stand out. The clustered-points pair changes one numbered cluster into individually selectable coffee markers as the map zooms closer; the cluster's count represents the combined points rather than a separate destination.

## Place-card presentation

| Inspected variant | Visible relationship to the map |
| --- | --- |
| iPad full callout | A detailed floating card is anchored near the selected marker while surrounding geography remains available. |
| iPad compact callout | A small summary limits how much of the map is obscured. |
| iPad caption/link | Minimal place text links onward to Apple Maps. |
| iPad sheet | A larger independent sheet prioritizes structured place information. |
| iPhone full presentation | Full details use a sheet appropriate to the narrower display. |

Choose detail according to the current task and available space, while leaving the selected location understandable.

## Indoor detail and context

The airport sequence progresses from surrounding city geography to terminal/gate structure, then individual amenities such as security, first aid, restrooms, and vertical circulation. The selected elevator has a distinct symbol/marker and a short information card. The nearby numbered floor control keeps level changes separate from panning and zooming.

A wider terminal example retains surrounding roads and buildings while keeping those supplemental areas visually quiet. The custom concourse example coordinates green map areas, gate/security icons, route-related rows, and the app's own navigation treatment; it demonstrates extending the app's identity rather than copying Apple Maps.

## Watch and appearances

The Watch example uses a compact region containing the relevant destination and nearby streets. The main guide preserves its static-snapshot interaction and annotation limit. Light/dark map pairs adapt land, building, road, label, card, and symbol contrast while preserving selected-place identity, zoom/detail hierarchy, and floor controls.
