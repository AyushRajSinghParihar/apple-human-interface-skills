# Eye interaction visual examples

Source: [Apple HIG eyes](https://developer.apple.com/design/human-interface-guidelines/eyes).

## Looking before activating

In Settings, attention moves among rows and changes the highlighted target while
the current screen stays open. This feedback identifies the element that an
indirect gesture can activate; looking alone does not navigate into each row.
Use system hover feedback to establish this distinction. The system's visible
response does not grant the app access to a person's pre-activation gaze data.
