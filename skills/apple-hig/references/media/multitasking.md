# Multitasking visual examples

Source: [Apple HIG multitasking](https://developer.apple.com/design/human-interface-guidelines/multitasking).

## Edges communicate the active window

Notes and Settings overlap slightly. As attention and activation move between
them, the system softens the edge of the window being left behind with a feathered
mask. This treatment helps explain which window is current without forcing the
person to reorganize the workspace. Avoid custom edge styling that conceals or
competes with this system feedback.
