# Platform and cross-topic routes

Read the target platform's introduction for a new surface, then its relevant
article sections. “Platform considerations” often contains exceptions that are
lost by applying only the shared best practices.

| Platform | Local starting point | Follow-up considerations |
|---|---|---|
| iOS | [Designing for iOS](../subskills/apple-hig-getting-started/references/designing-for-ios.md) | Touch, safe areas, adaptable bars, interruption and device changes |
| iPadOS | [Designing for iPadOS](../subskills/apple-hig-getting-started/references/designing-for-ipados.md) | Resizable windows, split views, sidebars, keyboard/pointer and Pencil |
| macOS | [Designing for macOS](../subskills/apple-hig-getting-started/references/designing-for-macos.md) | Menu bar, toolbars, windows, keyboard commands, precise pointer use |
| tvOS | [Designing for tvOS](../subskills/apple-hig-getting-started/references/designing-for-tvos.md) | Distant viewing, focus movement, remotes, shared viewing and text entry |
| visionOS | [Designing for visionOS](../subskills/apple-hig-getting-started/references/designing-for-visionos.md) | Spatial layout, eyes and gestures, comfort, ornaments and immersion |
| watchOS | [Designing for watchOS](../subskills/apple-hig-getting-started/references/designing-for-watchos.md) | Brief glanceable tasks, Digital Crown, small displays and haptics |

## Compose families for the user's task

| Task | Read together |
|---|---|
| Accessible scalable text | [Typography](../subskills/apple-hig-foundations/references/typography.md), [Accessibility](../subskills/apple-hig-foundations/references/accessibility.md), [VoiceOver](../subskills/apple-hig-technologies/references/voiceover.md) |
| Liquid Glass controls | [Materials](../subskills/apple-hig-foundations/references/materials.md), [Color](../subskills/apple-hig-foundations/references/color.md), the relevant control and platform sections |
| Arabic or Hebrew interface | [Right to left](../subskills/apple-hig-foundations/references/right-to-left.md), [Writing](../subskills/apple-hig-foundations/references/writing.md), [Layout](../subskills/apple-hig-foundations/references/layout.md), relevant icons and inputs |
| Spatial interaction | [Spatial layout](../subskills/apple-hig-foundations/references/spatial-layout.md), [Immersive experiences](../subskills/apple-hig-foundations/references/immersive-experiences.md), the input family and relevant ornaments/windows |
| Games | [Designing for games](../subskills/apple-hig-getting-started/references/designing-for-games.md), controllers, accessibility, audio, haptics, Game Center and purchases as applicable |
| Siri answer or action | [Siri](../subskills/apple-hig-technologies/references/siri.md), [Snippets](../subskills/apple-hig-system-experiences/references/snippets.md), privacy and relevant result controls |
| Glanceable system content | [Widgets](../subskills/apple-hig-system-experiences/references/widgets.md), [Live Activities](../subskills/apple-hig-system-experiences/references/live-activities.md), typography and privacy |
| Car interface | [CarPlay](../subskills/apple-hig-technologies/references/carplay.md), voice, relevant input and glanceability guidance |

Use the [topic index](topic-index.md) for exact article names. These combinations
are navigation aids, not a requirement to read unrelated guidance for every task.
